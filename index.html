Physics simulator — local only

The ball-trajectory simulator (boardwork_3d_mvp.html) calls a Flask API (app.py) for /api/simulate. GitHub Pages only serves static files, so this piece can't run here — there's nothing to deploy short of rewriting the physics in JavaScript or standing up a real backend.

To try it locally:

git clone https://github.com/thebenhawk/boardwork-3d.git
cd boardwork-3d
pip install -r requirements.txt
python app.py                  # Flask API on :5000
# open boardwork_3d_mvp.html in a browser

Worth knowing before you do: the current simulation loop can't actually produce a hook — board and entry angle are constant by construction. See the README for the details.
