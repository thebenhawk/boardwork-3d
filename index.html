Boardwork 3D

Two separate bodies of work: a validated oil-pattern renderer, and a physics-agent pipeline that isn't fully connected yet. See the README for the honest breakdown of what's real.

Lane Renderer Live here

Two-lane oil pattern renderer built on real Kegel sheet data — 11/11 patterns validated against their source sheets. Runs entirely in the browser, no backend.

Physics MVP Local only

The ball-trajectory simulator talks to a Flask API (app.py) for /api/simulate. That can't run on GitHub Pages — this is a static site with no backend — so this piece isn't deployed here. Clone the repo and run python app.py, then open boardwork_3d_mvp.html to try it locally. Worth knowing before you do: the current simulation loop can't actually produce a hook (see README).
